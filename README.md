# Product Sales Region Analysis
## Overview
This project contains a retail sales analysis dataset and dashboard workbook designed to analyze sales performance across different products, regions, stores, payment methods, promotions, and return statuses.

The workbook includes raw transaction data, cleaned data, pivot-table summaries, and dashboard components for business intelligence reporting and decision-making.
